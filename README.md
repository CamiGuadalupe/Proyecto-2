Panel Interactivo Inclusivo - Infraestructura y Comunicación en Informática

# Descripción del Proyecto
Este proyecto consiste en la creación de un panel interactivo cuyo objetivo principal es explicar de forma clara, visual y accesible el tema de infraestructura y comunicación en la informática. El diseño está orientado a ser lo más inclusivo posible, considerando aspectos de accesibilidad sensorial, física o cognitiva, según las necesidades del público objetivo.

# Objetivo
Diseñar y construir un panel interactivo de dimensiones aproximadas de 50x70 cm o 60x90 cm, que permita al usuario experimentar y comprender conceptos relacionados con la infraestructura y la comunicación en el ámbito informático.

# Requisitos 
Cada panel debe incluir como mínimo los siguientes elementos:

- Un mecanismo impreso en 3D, preferentemente accionado mediante un servomotor.
- Un sensor (por ejemplo, ultrasónico, de proximidad, infrarrojo, etc.) que dispare algún tipo de interacción con el usuario.
- Un componente de proyección o mapping visual, que puede ser manual o automatizado.
- Un microcontrolador Arduino UNO, encargado de controlar las distintas interacciones del panel.
- Un diseño de experiencia que contemple al menos un tipo de accesibilidad: sensorial, física o cognitiva.

# Enfoque de Inclusión
El proyecto está pensado para facilitar la comprensión del contenido a través de elementos interactivos que involucren varios sentidos, permitiendo que personas con diferentes tipos de capacidades puedan participar e interactuar con el panel de manera efectiva.# Proyecto-2
